# East Coast Job Market Analysis

## Project Overview

This project analyzes data and analytics job opportunities across the U.S. East Coast, with a focus on New Jersey, New York, Washington, D.C., Virginia, and Maryland.

The goal is to compare job availability, required skills, and regional differences for entry-level data-related positions.

## Research Questions

- Which East Coast locations offer the most data and analytics job opportunities?
- What technical skills are most frequently requested?
- Which job titles appear most often?
- How do job opportunities differ across locations and industries?

## Tools

- Python
- pandas
- Matplotlib
- Jupyter Notebook
- Microsoft Excel

## Planned Analysis

1. Collect job-posting data
2. Clean and organize the dataset
3. Analyze job titles, locations, skills, and industries

5. Summarize key findings
